# 漫时光 · MANSHIGUANG

以「夜航星海」为视觉主题的二次元动漫网站原型，强调沉浸、精致与轻赛博感，不用门户模板式布局。零依赖静态站点，无需安装依赖或构建。

## 快速启动

双击 `start.bat`：启动本地服务并打开 `http://127.0.0.1:4173/`。停止用 `stop.bat` 或服务器窗口 `Ctrl+C`。手动运行：

```powershell
python server.py 4173
```

本地服务只监听 `127.0.0.1`。经它启动时，画布「打开目录」会真正唤起资源管理器，资产库通过 `/__gallery_asset/` 读项目外数据；改用普通 `python -m http.server` 则「打开目录」退化为页内列表、资产页读不到外部索引。

也可直接双击 `index.html` 看主站基础界面；但画布的目录授权、文件保存与网络请求建议走本地 HTTP。在线字体离线时自动回退系统中文字体。

## 功能

- **主站**：沉浸式首页 Hero + 星光背景；12 部原创虚构番剧（分类筛选、搜索、详情弹层）；本周排行榜、每日新番表、社区内容；追番收藏（`localStorage`）；选集切换、移动端菜单、键盘快捷键（`/` 搜索、`Esc` 关闭）、基础无障碍。
- **AI 创作工作台**（`studio/index.html`，新标签页）：左侧工作区栏集成「画布」「图片工坊」「剧情导演台」三个在线工作区 + 设定与出图、数字人视频、任务与成片三个规划占位。切走的工作区只隐藏不销毁，工作流与已载索引保留；工作台左下角授权一次资产目录，画布直接共用。
- **资产参考库**（`gallery/index.html`，新标签页）：姿势 1,439 / 服装 3,224 / 人像 1,499 条，三库合一，中文搜索、分类筛选、安全模式、详情浏览、多视角与深度图切换；画布内左侧「姿势库/服装库/人像库」可开右侧抽屉，选中一键插入画布生成图片节点。
- **画布**：节点式工作流编排、导入/导出、AI 服务商配置、素材上传与生成结果管理；本地/云端 ComfyUI 生图；「+」与右键「添加节点」含视频节点（当前 bundle 无视频模型，运行会提示 `Video model config is missing`，不发请求）。
- **API 来源**：保留内置「云雾」+ 任意多个第三方，同时只启用一个；第三方自动拉取模型可勾选，图片节点只显示已选模型；API 配置固定存于 `C:\Users\liliang\msg\manshiguang-api-config.json`（明文含 Key，只放本人可控目录）。

快捷键：`/` 打开搜索，`Esc` 关闭详情/搜索/移动菜单。

- **画布**（在线）：节点编排、生成、素材上传

- 设定与出图 / 数字人视频 / 任务与成片（规划中，只显示用途/输入/产出/关系，不放假按钮）
- **设置**（在线，在「任务与成片」下方）：把画布的「模型与接口设置」整页化，顶栏为设置分区切换（「API设置」+「SKILL模板」，后续其它设置在此加分区，不再新增左栏项）；API设置分区只显示五个接口分区（文本 / 图片 / 视频 / 语音 API / ComfyUI），默认开在「图片API来源设置」。配置与画布共用同一份本地数据；改完点顶部「应用到画布」，画布重新载入即生效。资产目录、快捷键与「从本地恢复」仍在画布「常规设置」里。
- **SKILL模板**（设置页第二个分区）：固定「怎么写」的提示词骨架。内置四个 SKILL（短剧剧本 / 视觉资产 / 图片提示词 / H3 分镜）只读，可「另存为自定义」后编辑；自定义模板可新建、删除、复制正文、导入导出 JSON。模板只在本页管理，画布节点暂未接入。

## 画布使用

两种入口：工作台内「画布」工作区（推荐），或独立 `canvas/index.html`（需完整窗口尺寸时）。画布由打包好的 React 前端 + 一组补丁组成（`web-bridge.js` 提供 `window.electronAPI`，品牌/迁移/API/ComfyUI/模型/资产/视频补丁各管一块，均不改压缩 bundle）。

### API 来源配置
「模型与接口设置 → 图片API来源设置」保留云雾并支持多个第三方，每张卡含申请地址、API Key、Base URL 与「启用」按钮，同时只启用一个。配置存 `localStorage["manshiguang:canvas-api-profiles"]`，启用项同步到 `canvas-api-settings`。

### 文本 API 来源配置
「模型与接口设置 → 文本API来源设置」（在「图片API来源设置」**上方**）用于给画布「文本节点」单独指定文本 API，卡片界面与图片 API 设置保持一致。配置存 `localStorage["manshiguang:canvas-text-api-profiles"]`。

默认内置一张「云雾」卡（徽标「内置」、不可删除），云雾的文本接口与图片接口是分开配置的，请在此自行填写云雾的 API Key 与 Base URL（申请地址已内置）；模型名可留空，留空时沿用画布自带的云雾文本模型，填写后改用该模型名。需要其它服务商时点「＋ 新增第三方 API」加卡，填配置名称、申请地址（可选）、API Key、Base URL，再「测试连接并拉取模型」或直接在「模型名」里手填，最后从下拉选定文本模型并「启用」；第三方必须填齐 API Key、Base URL 与文本模型名才能启用，缺项时点「启用」会被拦截并提示缺什么。同时只启用一个，删除正在启用的第三方卡会自动回到内置云雾。接管后画布文本请求改用当前启用配置的 Key、Base URL 与模型名，生图、生视频请求不受影响。第三方需兼容 OpenAI 风格 `POST /v1/chat/completions`。浏览器直连被跨域拦截时自动经本机 `server.py` 的 `/__textapi/` 转发，因此用第三方地址请保持 `start.bat` 运行；若 `server.py` 还是旧版本会提示「请重启 start.bat」。

### ComfyUI 设置
「图片API来源设置」下方的独立「ComfyUI设置」tab，本地/云端两卡同时只启用一个。本地默认 `http://127.0.0.1:8188`，云端填 `https` + 访问密钥（经 `X-MS-Comfy-Key` 头由 `server.py` 转 `Authorization: Bearer`，不进 URL）。启用后自动列出 `workflows` 目录工作流，选中时读取并校验 `nodes` 数组。

生图流程：ComfyUI 里保存工作流 → 画布 ComfyUI 设置里选它 → 下方「生成」区列出可改参数（提示词/种子/步数/cfg/宽高/底模，默认只显常用项）→ 点「开始生成」真实执行，轮询进度（最长 30 分钟，「取消等待」只停轮询）→ 完成后自动插入画布成新图片节点并进合成台。安全边界：本机 ComfyUI 无「只校验」模式，`/prompt` 一提交即真跑，只有你明确点「开始生成」才发任务；含子图的工作流会自动展平后照常使用；含前端虚拟节点（rgthree 分组/Label/存取值等）或子图定义缺失的工作流无法保证转换一致，会显示「无法自动转换」并禁用按钮。

### API 配置存储
「常规设置 → API 配置存储」固定 `C:\Users\liliang\msg`，首次保存/恢复弹一次目录授权，之后自动读写 `manshiguang-api-config.json`（Key/URL/勾选变化自动续写）。文件明文含 Key，勿放公开目录或版本库。浏览器拿不到绝对路径，`webdir:<uuid>:<encoded-name>` 是内部标识非 Windows 路径；目录名为 `images` 时显示层固定标注 `D:\data\workData\漫时光\画布\images`（仅展示）。资产目录与 API 配置目录独立，保存不会改资产目录。

### 第三方模型列表
填第三方 Base URL 后自动拉 `${base}/v1/models`（404 再试 `${base}/models`），可「拉取全部模型」；首次默认勾图片模型，同源刷新保留勾选。图片节点下拉只显示当前启用 Profile 的已选模型，切回云雾恢复原生 4 模型与文案。Grsai 请求统一转发到 `/v1/api/generate`（nano-banana 发 `aspectRatio+imageSize`，gpt-image 发像素+`quality`），经 `/v1/api/result?id=` 轮询；文本节点可改用「文本API来源设置」的独立配置。

### 浏览器版限制
画布非 Electron 桌面版等价替代：CORS 不能前端绕过；浏览器读不了任意本地绝对路径（用上传或 Chromium 选素材目录，绝对路径需配合本浏览器目录授权/映射，不能拷到别的机器/浏览器）；仅 `start.bat`/`server.py` 启动时才能对固定白名单目录唤起资源管理器；无 FFmpeg（视频剪辑会报错）；代理配置不改浏览器网络栈；选素材目录后节点下载优先写该目录（目录名即 `images` 时不再套一层），未授权/失败才回退浏览器下载；同名同内容直接复用不产生 `-2`。
