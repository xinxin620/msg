# 漫时光 · MANSHIGUANG

一个以「夜航星海」为视觉主题的二次元动漫网站原型。整体强调沉浸、精致和轻赛博感，不使用传统门户模板式布局。

## 快速启动

双击项目根目录的 `start.bat`，会启动项目自带的本地服务并自动打开 `http://127.0.0.1:4173/`；AI 创作工作台与资产参考库从主站顶部导航进入。停止时双击 `stop.bat`，或在服务器窗口按 `Ctrl+C`。也可以手动运行：

```powershell
python server.py 4173
```

本地服务只监听 `127.0.0.1`。通过它启动时，画布资产目录的「打开目录」会真正唤起 Windows 资源管理器；资产参考库则通过 `/__gallery_asset/` 只读代理访问项目外的参考数据目录。如果改用普通 `python -m http.server`，画布按钮会自动回退为页面内「查看目录」，资产页也无法加载本地索引与图片。

也可以直接双击 `index.html` 浏览主站基础界面。项目为零依赖静态站点，不需要安装依赖或构建；但画布的目录授权、文件保存和网络请求建议通过 `start.bat` 启动的本地 HTTP 地址使用。

> 在线字体需要网络；离线时会自动回退到系统中文字体，不影响页面使用。

## 资产参考库

从主导航「资产」在新标签页打开 `gallery/index.html`。页面延续「夜航星海」视觉，读取本机下载的 `D:\data\workData\codex\Projects\ai-pose-gallery-zh-main`，不会把图片或索引复制进本仓库。

- 服装库：`3,224` 条，包含现实服装、Shisei 中国历代服装和两类远程二次元服装；Shisei 支持正面、斜侧、侧面、背面多视角。
- 人像库：`1,499` 条，支持分区、发长、热门与精选筛选。
- 默认开启安全模式：姿势隐藏「全身单人・性感系」「双人缠绵」，服装隐藏「内衣・睡衣」「性感穿搭」以及 `敏感: true` 条目。关闭前会弹出 18+ 确认。实际安全模式显示 `4,769` 条，全部显示 `6,162` 条。
- 详情弹层支持上一张/下一张、`←` / `→` 与 `Esc`；卡片支持懒加载与失败占位。

本地图片通过 `server.py` 的只读接口访问：

```text
GET /__gallery_asset/data/*.json
GET /__gallery_asset/thumbs/*
GET /__gallery_asset/img/*
```

接口只允许 `data`、`thumbs`、`img` 三个根目录及 JSON/JPG/PNG/WebP/GIF/AVIF 文件，会拒绝路径穿越、反斜杠、NUL 和越界路径。数据目录可在启动前通过环境变量覆盖：

```powershell
$env:MSG_GALLERY_DIR = 'D:\某个\ai-pose-gallery-zh-main'
python server.py 4173
```

若 4173 端口仍是旧版服务，资产页会显示读取失败；请结束旧服务后重新双击 `start.bat`。CharaDB 与「ギア・动漫」两组图片使用远程源站 URL，真实可用性取决于对方站点与浏览器网络环境，尚未做跨域和长期可用性承诺。

图片和原始数据不适用本仓库的 MIT 许可证，版权归各原作者所有；默认隐藏敏感分类，仅限个人学习、人体动态研究与合法创作，禁止打包倒卖或侵权使用。

## 画布使用

画布有两种打开方式：在「AI 创作工作台」里作为工作区使用（推荐，资产目录授权和图片工坊都在同一页），或按下面的独立入口直接打开完整窗口。

画布入口：

- 工作台内：`studio/index.html` → 左侧「画布」
- 独立入口：`canvas/index.html`（不经主站导航，适合需要完整窗口尺寸时用）
- 打开方式：均为浏览器新标签页（`target="_blank"`）

画布由已打包的 React 前端、`canvas/web-bridge.js`、`canvas/branding-patch.js`、`canvas/api-profiles-patch.js`、`canvas/comfy-workflow.js`、`canvas/comfy-patch.js`、`canvas/model-patch.js` 和 `canvas/gallery-patch.js` 组成。桥接层提供与原 Electron preload 同名的 `window.electronAPI`，用于把桌面版文件、网络和窗口能力映射到浏览器可用的能力；品牌补丁替换设置侧栏作者信息，并通过带日期的唯一文件名和版本参数刷新收款码；API 来源补丁负责拉取并勾选模型，ComfyUI 补丁提供本地/云端连接配置与真实工作流选择，模型补丁只展示已选模型并适配 Grsai 请求协议，不修改压缩 bundle。

### API 来源配置

「模型与接口设置 → 图片API来源设置」支持在保留内置「云雾」的同时新增任意多个第三方 API。每张配置卡都包含申请地址、API Key 和 Base URL，并保留「申请」按钮；其右侧的「启用」按钮用于切换当前配置，同一时间只有一个配置处于启用状态。

配置保存在 `localStorage["manshiguang:canvas-api-profiles"]`，刷新页面后继续保留。启用项会同步到画布原有的 `canvas-api-settings`，后续请求使用当前配置的 Key 与 Base URL。

### ComfyUI 设置

「模型与接口设置 → 图片API来源设置」正下方新增独立「ComfyUI设置」tab，内含「本地 ComfyUI」和「云端 ComfyUI」两张配置卡，同一时间只启用一个。

本地默认地址为 `http://127.0.0.1:8188`，仅允许本机 `http` 地址；云端需要填写 `https` 地址，服务要求鉴权时可在「访问密钥」中填写。密钥通过本地代理的 `X-MS-Comfy-Key` 请求头传给 `server.py`，由服务转为上游 `Authorization: Bearer`，不会写进 URL。

「测试连接」会经 `server.py` 的 `/__comfy/system_stats?base=...` 转发，避免浏览器与 ComfyUI 的跨源限制；测试时需要 `server.py` 正在运行。启用本地 ComfyUI 后，卡片会自动读取真实 `workflows` 目录，支持搜索、刷新和点击选择；选中时会读取工作流 JSON 并校验 `nodes` 数组，保存节点数量、文件大小和更新时间，并立即解析成可执行任务。

配置与选中的工作流保存在 `localStorage["manshiguang:canvas-comfyui"]`，当前启用项会发布到 `window.__MS_COMFY__`。

### 用 ComfyUI 在画布里生图

1. 在 ComfyUI 里把调好的工作流**保存**（保存后会进入 `workflows` 目录）。
2. 画布打开「模型与接口设置 → ComfyUI设置」，启用本地或云端 ComfyUI，在「工作流」列表里搜索并点选它。
3. 选中后下方「生成」区会自动列出可修改的参数：提示词 `text`、随机种子 `seed`、步数 `steps`、`cfg`、宽高、底模名等。默认只显示常用项，可点「显示全部 N 个参数」展开；没有命名记录的旧参数只读。
4. 改完提示词点「开始生成」，任务会提交给你的 ComfyUI 真实执行，画布显示「正在排队 / 正在生成…（已等待 N 秒）」，最长等待 30 分钟，可随时「取消等待」（只停止画布轮询，不会中断 ComfyUI 里已在跑的任务）。
5. 完成后结果自动**插入画布成为新的图片节点**，同时进入右侧合成台，并可在「生成」区看到缩略图（点开是新标签页原图）。落盘仍走与资产插入相同的目录授权路径。

安全边界：本机 ComfyUI 没有“只校验不执行”的模式，`/prompt` 一旦提交就是真跑，所以只有你明确点「开始生成」才会发出任务，画布不会自动提交。另外，含有**子图**节点、或使用了 `Fast Groups Bypasser (rgthree)`、`Label (rgthree)`、取值/存值等**只在前端生效的节点**的工作流，画布无法保证转换结果与 ComfyUI 自己的一致，会显示「无法自动转换」并说明原因、保持「开始生成」禁用，而不会冒险跑出错误的图。这类工作流请在 ComfyUI 里展开子图、去掉分组开关后另存为新工作流再选。

转换规则不是猜的：以 ComfyUI 官方前端 `graphToPrompt` 导出的 API 格式为基准逐字段对账（连线穿透、跳过静音/旁路节点、剔除前端专用控件等），当前 23 个工作流里 12 个做到逐字段完全一致，其余被判定为不可安全转换并给出原因。

### API 配置存储

「模型与接口设置 → 常规设置 → API 配置存储」固定显示应用数据目录 `C:\Users\liliang\msg`，不再提供浏览器存储切换。请先确保该目录存在；首次点击「立即保存」或「从本地恢复」时，浏览器会打开一次 Windows 目录选择窗口，选中该目录完成授权。之后保存会自动创建或覆盖固定文件 `manshiguang-api-config.json`，修改 API Key、Base URL 或模型勾选时也会自动续写；「从本地恢复」会把该文件重新载入画布。旧版本留下的浏览器存储状态会自动迁移为目录模式。存储模式和授权信息记录在 `localStorage["manshiguang:canvas-api-storage"]`，刷新后保留。

本地文件是**明文 JSON**，会包含 API 密钥，只能放在本人可控的私有目录；该文件只属于当前设备，不会同步到服务器。浏览器不能自行创建或写入未授权的 Windows 绝对路径，因此首次使用必须手动选择并授权一次目录。

「立即保存」和「从本地恢复」在 `20261104-20` 版本修复了点击无效的问题：此前卡片把序列化后的 HTML 与模板字符串直接比较，浏览器会规范化 `disabled` 等布尔属性导致比较永远不成立，卡片每秒重绘约 60 次，按钮节点被反复替换。现在改为缓存上一次渲染的模板，点击会立即进入保存或读取状态。

资产存储目录输入框里的 `webdir:<uuid>:<encoded-name>` 是浏览器为已授权目录生成的内部标识，并非 Windows 路径（例如 `%E7%94%BB%E5%B8%83` 解码后是「画布」）。页面出于安全限制拿不到绝对路径，真实标识保留在元素属性和悬停提示中；选择目录、查看目录和媒体读写仍使用该标识。为方便识别，当前页面在授权文件夹名为 `images` 时，显示层固定标注用户确认的实际路径 `D:\data\workData\漫时光\画布\images`；该路径只用于展示，不参与读写。资产目录与 API 配置目录各自独立，点「立即保存」不会改写资产目录。

`20261107-2` 起，资产库可以在画布内直接打开。点击画布左侧的「姿势库 / 服装库 / 人像库」，资产库会以抽屉形式在画布右侧滑出，挑好图点一下就能插入画布生成图片节点，不用再在新标签页和画布之间来回切换。抽屉里的搜索、筛选、安全模式与独立资产页完全一致，并且只加载当前这个库的索引，所以打开更快。仍想全屏浏览或对照多张图时，点抽屉右上角「新标签页」，或按住 Ctrl 再点库按钮。注意：用独立标签页发送的资产只会进入合成台列表，不会自动建节点。

`20261107-1` 起，重复上传同一张图片不会再往资产目录里塞副本。此前如果你直接从 `D:\data\workData\漫时光\画布\images` 里选图上传，画布为了不覆盖同名文件会自动改名另存一份（`xxx-2.png`、`xxx-3.jpg`），看起来就像「传一张多出两张」。现在保存前会先比较文件内容：完全相同就直接复用原文件，只有内容确实不一样才另起新名。之前已经产生的重复文件属于历史数据，画布不会自动删除，需要的话手动清理即可。

### 第三方模型列表

添加第三方配置并填写 Base URL 后，`canvas/api-profiles-patch.js` 会自动尝试 `${base}/v1/models` 与 `${base}/models`；也可以点击「拉取全部模型」。首次拉取默认勾选图片模型，之后可在模型列表中逐项勾选、全选图片或清空，并可用「拉取全部模型」刷新目录。模型目录与勾选保存在 `localStorage["manshiguang:canvas-api-profiles"]`，刷新后保留；同源重新拉取只保留仍存在且此前勾选的模型，不无故覆盖用户选择。

`canvas/model-patch.js` 只把当前启用 Profile 的 `selectedModels` 注入图片节点下拉。未勾选任何模型时显示配置提示；切回云雾时恢复画布原生的 4 个模型和原始按钮文案。当前 Grsai 返回 30 个模型，其中 16 个 `gpt-image-*` / `nano-banana-*` 图片模型。单次节点选择另存于 `localStorage["manshiguang:canvas-model-choice"]`。

Grsai 的请求协议与云雾不同：画布仍调用 OpenAI 风格 `/v1/images/generations`、`/v1/images/edits`，Banana 系列还可能调用 `/v1beta/models/<model>:generateContent`。补丁会统一转发到 `POST /v1/api/generate`，nano-banana 使用 `aspectRatio + imageSize`，gpt-image 使用像素尺寸与 `quality`，随后通过 `GET /v1/api/result?id=...` 轮询结果。文本节点暂未接入第三方文本模型，仍使用原画布云雾模型名。

### 浏览器版能力限制

画布不是原 Electron 桌面版的完全等价替代：

- AI 服务商、上传服务和 OSS 端点若未允许跨域，浏览器请求会失败；CORS 不能由前端绕过。
- 浏览器无法读取任意本地绝对路径。请使用画布上传，或在支持的 Chromium 中先选择素材目录。节点里显示的绝对路径需要配合本浏览器的目录授权与映射记录才有效，不能复制到另一台机器或另一个浏览器直接打开。
- 只有通过 `start.bat`/`server.py` 启动时，画布才能对固定白名单目录唤起系统资源管理器；直接使用普通静态服务器或双击 HTML 打开时，会回退为页面内查看文件列表。
- 网页版没有 FFmpeg，视频剪辑接口会明确报错。
- 自定义网络代理属于浏览器外部配置，画布设置页中的代理不能接管浏览器网络栈。
- 已选择素材目录时，图片/视频/音频节点右上角的下载按钮会优先写入该目录；如果目录名本身就是 `images`，文件直接落在这个目录里，不会再套一层 `images`。只有尚未授权目录或写入失败时，才回退为浏览器下载。同名且内容一致的文件会被直接复用，不产生 `-2` 副本。
- 未选择素材目录时，保存操作会回退为浏览器下载；不会写入原桌面版的默认资产目录。
- 第三方模型列表依赖平台 `/v1/models` 的 CORS；实际出图仍需要有效的第三方 API Key。当前只适配了图片节点，文本节点仍使用原云雾模型名。
- 选择本地 API 配置目录后，导出的 `manshiguang-api-config.json` 是明文文件，包含 API Key；请避免放在公开目录、公共网盘或版本库中。
- 画布内窗口最大化使用 Fullscreen API；浏览器新标签页的关闭行为由浏览器控制。

## 内容与后续接入

当前 12 部番剧、制作公司、社区帖子和用户均属演示用虚构内容。画布 bundle 属于从外部桌面应用提取的预构建前端，升级时不要直接修改压缩文件，应整体替换后重新核对桥接接口、`branding-patch.js` 的文本选择器和 `api-profiles-patch.js` 的 vendor 卡片选择器。

后续正式上线时建议依次接入：

1. 番剧内容 API 与后台管理
2. 用户登录、追番同步和多端收藏
3. 视频播放器、清晰度切换和播放进度
4. 真实搜索服务、社区发布与内容审核
5. 画布后端代理，用于规避 CORS、安全保存第三方 API Key 和执行服务端 FFmpeg
6. 访问统计、SEO、分享卡片和部署配置

播放器、登录、社区后端和画布后端目前均未接入，相关操作会以演示提示或明确的浏览器能力错误反馈。
