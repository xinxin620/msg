## 实体与接口
- **Workflow**：节点/边/分组/名称/参数，导入导出 `.json`/`.dtworkflow`。
- **API Profile**：`id/name/apiKey/baseUrl/applyUrl/builtin`；第三方另 `modelCatalog/selectedModels/modelsFetchedAt/modelsError/modelsBaseUrl`；云雾 ID 固定 `yunwu`。
- **文本 API Profile**（state `version:3`）：`id/name/apiKey/baseUrl/applyUrl/textModel/builtin` + `modelCatalog/selectedModels/modelsFetchedAt/modelsError/modelsBaseUrl`；内置云雾 `id:"yunwu"`、`builtin:true` 恒在首位且不可删除，`activeId` 默认 `yunwu`；`textModel` 仅第三方必填（内置留空＝沿用画布自带云雾模型名）。
- **视频 API Profile**（state `version:1`）：`id/name/apiKey/baseUrl/applyUrl/videoModel/builtin` + `modelCatalog/selectedModels/modelsFetchedAt/modelsError/modelsBaseUrl`；内置云雾 `id:"yunwu"`、`builtin:true` 恒在首位且不可删除，`activeId` 默认 `yunwu`；`videoModel` 仅第三方必填（内置留空＝沿用画布原视频模型）。
- **ComfyUI 连接配置**：`version/activeId/profiles`（固定 `local`/`cloud`，各含 `name/baseUrl/apiKey`+可选 `selectedWorkflow`）；`activeId` 唯一，地址变化则该工作流选择失效。
- **ComfyUI 提交**：`{prompt:{"<节点id>":{class_type,inputs}}}`，节点 id 用编辑格式原始数字字符串，连线 `[上游id,输出槽]`；完成看 `history/<promptId>`（`status_str==="error"` 失败）否则 `queue_running`/`queue_pending`；结果在 `outputs[*].images[]`，`view?filename&type&subfolder` 取回。
- **`/__textapi/` 代理**：`GET/POST /__textapi/proxy?url=<绝对地址>`，文本与视频 API 共用，仅本机客户端；只做 http/https 绝对地址校验，`Authorization` 原样透传（不进 URL、不落盘）；404「接口不存在」= server.py 是旧版，需重启 `start.bat`。
- **`/__comfy/` 代理**：`GET/POST /__comfy/<path>?base=<url>`，只允本机 http 或 https，拒远程 http 与越界，仅本机客户端；`X-MS-Comfy-Key` 转上游 Bearer。

## 浏览器能力边界
- CORS 不能绕过；桥接层不接管系统代理。
- 读不了任意 Windows 绝对路径，需上传或 Chromium 选素材目录；`webdir:` 是 handle 键非路径。
- 资源管理器打不开；「查看目录」靠 `server.py` 白名单接口（仅 `D:\data\workData\漫时光\画布\images` 与 `C:\Users\liliang\msg`），结果用 `manshiguang:directory-opened` 事件回传。
- `clipVideo()` 网页版必失败（无 FFmpeg）；最大化用 Fullscreen API，`window.close()` 受策略限制。
- `showDirectoryPicker()` 须在点击处理首个 `await` 前调用否则丢激活；iframe 内授权不可靠须顶层窗口做。
- 文件保存优先 File System Access 写已授权目录，失败才回退下载。
